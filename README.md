Data Cleaning and Transformation

📌 Project Overview

This project focuses on **Data Cleaning and Transformation using Microsoft Excel** as part of my Data Analytics learning journey.

The objective of this assignment is to clean, standardize, and transform a product dataset by handling missing values, correcting inconsistencies, removing duplicate records, restructuring columns, and applying formatting techniques.

This project demonstrates my practical knowledge of Excel data preprocessing techniques and my ability to prepare raw data for further analysis.

🎯 Objectives

* Identify and handle missing values in the dataset.
* Correct inconsistent text formats and spelling errors.
* Identify and remove duplicate records.
* Split and merge columns to improve data structure.
* Apply appropriate number and date formatting.
* Use conditional formatting to highlight important information.
* Prepare a clean and structured dataset for analysis.

📂 Dataset Description

**Dataset Name:** Product Dataset

**Attributes:**

* Product ID
* Product Name
* Brand Name
* Quantity
* Category
* Price

The dataset contains product information, including product names, brands, quantities, categories, prices, and manufacturing details.

🛠️ Tools and Technologies

* **Microsoft Excel**
* Find and Replace

* Excel formulas and functions
* Number Formatting
* Conditional Formatting

📊 Tasks Performed

1. Handling Missing Values

* Identified missing values in the Price and Category columns.
* Evaluated suitable methods to handle missing information.
* Used appropriate techniques to maintain data quality and consistency.

2. Correcting Inconsistent Data

* Identified inconsistent text formats in the Product Name column.
* Identified spelling mistakes and inconsistencies in the Category column.
* Used Excel's **Find and Replace** feature to standardize product names and correct category values.

3. Removing Duplicates

* Checked the dataset for duplicate records using all columns.
* Used Excel's **Remove Duplicates** feature to eliminate identical rows.
* Maintained unique records in the cleaned dataset.

4. Splitting and Merging Data

* Split the Product ID column into two separate columns:

  * Manufacturing Date
  * Country Code
* Removed unnecessary characters and structured the extracted information.
* Merged the Brand Name and Product Name columns into a new column named **Product Brand**.

5. Number Formatting

* Applied currency formatting to the Price column for better readability.
* Formatted the Manufacturing Date column using the **DD-MM-YYYY** date format.

6. Conditional Formatting

* Applied **Data Bars** to the Price column to visually compare product prices.
* Created a custom conditional formatting rule to highlight cells where the Category is **Electronics**.
* Improved the readability and visual presentation of the dataset.

📈 Key Outcomes

* Prepared a structured and cleaned product dataset.
* Improved data consistency by correcting text formats and spelling errors.
* Removed duplicate records to improve data quality.
* Restructured product information into meaningful columns.
* Improved the readability of prices and manufacturing dates.
* Used conditional formatting to make important data easier to identify.
